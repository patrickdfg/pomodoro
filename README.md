# Study Bunny

토끼와 함께하는 아기자기한 집중 · 할 일 앱입니다. 첨부된 Study Bunny 시안의 분홍색·크림색 팔레트, 공부방 일러스트, 원형 타이머, 할 일 목록, 꾸미기 화면을 실제 웹 인터페이스로 구현했습니다.

- **홈**: 오늘 날짜, 할 일과 완료율. PC에서는 홈·타이머·할 일/꾸미기를 나란히 표시합니다.
- **타이머**: 기본 25분 집중, 5분/15분 휴식, 자유 시간 설정. 4회 집중마다 긴 휴식을 안내합니다. 사용자가 시작을 눌러 다음 세션을 시작합니다.
- **할 일**: 날짜와 아이콘을 지정해 추가, 완료/취소, 삭제. 오늘·이번 주(월~일)·전체·완료 필터.
- **꾸미기**: 같은 공부방 일러스트를 기반으로 한 여섯 가지 색감과 세 가지 소품.
- **공부 기록**: 완료한 집중/자유 세션의 시간, 포모도로 횟수, 최근 7일 기록, 하루 목표.

휴대폰에서는 하단 메뉴로 화면을 전환합니다. 타이머 설정, 진행 중인 타이머, 할 일, 꾸미기와 기록은 브라우저의 localStorage에 저장합니다. 브라우저 데이터를 삭제하면 기록도 삭제됩니다. 저장 기능이 차단된 환경에서는 현재 화면에서 사용할 수 있지만 재접속 시 복원되지 않습니다. 다른 기기와의 동기화는 지원하지 않습니다.

타이머는 종료 시각을 기준으로 남은 시간을 계산하므로 백그라운드에서 간격이 늦어져도 복귀 시 보정됩니다. 집중 시간은 세션을 끝까지 완료했을 때 기록됩니다. 화면을 닫은 동안의 완료는 다음 접속 때 반영됩니다. 알림음은 사용자의 시작 버튼 입력으로 활성화되며 기기/브라우저의 소리 설정을 따릅니다.

## 실행

빌드 없이 정적 호스팅에 루트 파일을 그대로 올릴 수 있습니다. GitHub Pages에서도 하위 경로로 작동합니다. 로컬 실행에는 Node.js 20 이상을 사용합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. Google Fonts에서 Gaegu, Nunito, Noto Sans KR을 불러오며 연결되지 않으면 기기 글꼴을 사용합니다. 그림과 앱 아이콘은 저장소에 포함되어 있습니다.

## 검증

```sh
npm ci
npx playwright install chromium
npm test
```

설치된 Microsoft Edge를 사용할 때는 `BROWSER_CHANNEL=msedge` 환경 변수를 지정합니다. 테스트는 할 일 저장·필터·안전한 텍스트 표시, 타이머 정지/복원/완료/긴 휴식, 공부 기록과 목표, 테마 저장, 320/390/768/1440px에서 모든 화면의 가로 넘침 여부, 손상된 저장 데이터 복구를 확인합니다.

## 디자인 에셋

[공부방 일러스트와 생성 프롬프트](assets/README.md). 원본 시안의 포스터나 휴대폰 테두리를 이미지로 덮지 않고, 실제 버튼과 입력 폼으로 구현했습니다. 일러스트는 시안을 참고해 새로 생성했으므로 원본과 완전히 동일하지는 않습니다.
